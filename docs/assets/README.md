# BiliDl icon assets

The selected launcher mark is the **left-hand concept from the generated two-icon sheet**.

- `bilidl-icon-generated-left.webp` is a 512 px repository preview of that original concept.
- `app/src/main/res/drawable-nodpi/bilidl_tv_download_foreground.png` is the foreground extracted from that exact concept. The pink field is transparent so Android can apply the adaptive-icon mask and background.
- `app/src/main/res/drawable-nodpi/bilidl_tv_download_monochrome.png` is its single-colour themed-icon mask.
- Both adaptive launcher resources point to these generated-artwork-derived assets.

The separate SVG file is an earlier hand-drawn vector exploration; it is **not** the launcher artwork.

# BiliDl icon assets

The Android launcher uses the **left-hand concept from the original generated two-icon sheet**.

- `bilidl-icon-generated-left.webp` is the 512 px preview of that exact concept.
- `app/src/main/res/drawable-nodpi/bilidl_tv_download_foreground.png` is the transparent foreground extracted from the original generated artwork.
- `app/src/main/res/drawable-nodpi/bilidl_tv_download_monochrome.png` is the corresponding Android themed-icon mask.
- Both adaptive launcher resources use those original-artwork-derived PNGs and a pink gradient background matching the source concept.

The launcher does not use the earlier hand-redrawn SVG exploration.
